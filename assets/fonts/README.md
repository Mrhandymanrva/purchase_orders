# Noto Sans

These fonts are bundled for server-side PDF reports and embedded as subsets.

- Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- Files: NotoSans-Regular.ttf and NotoSans-SemiBold.ttf
- License: SIL Open Font License 1.1; the original notice is retained in OFL.txt.
- Downloaded September 14, 2026. No font modifications were made.

The Next.js outputFileTracingIncludes setting includes the fonts and license in standalone deployments. Reports do not fetch fonts over the network.
